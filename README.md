# Aprameya Satish — Personal site

Academic site for [Aprameya Satish](https://www.linkedin.com/in/aprameya-satish/), Senior Research Engineer at GTRI.

## Pages

- `index.html` — Overview + private contact form
- `research.html` — Research programs, education, service
- `experience.html` — Role history
- `publications.html` — Full bibliography
- `resume/` — LaTeX CV source (not linked from the public site)

## Private contact form

The site never shows a personal email. Messages go through [Web3Forms](https://web3forms.com) (free forever, 250 submissions/month).

Configure the access key in `contact-config.js` (already set for this site). Your notification email stays in the Web3Forms dashboard.

## Local preview

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.
